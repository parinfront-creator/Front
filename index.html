📖 วิธีใช้ (ทำเดือนละครั้ง)
  1. สิ้นเดือน กด 📝 โหมดจดมิเตอร์ทีละห้อง แล้วใส่เลขมิเตอร์ไฟ/น้ำทีละห้อง
  2. เช็กว่าไม่มีตัวหนังสือสีแดงเตือน (เลขผิดปกติ)
  3. กด 🖼️ ส่งรูปไลน์ หรือ 💬 คัดลอกข้อความ ในแต่ละห้อง หรือกด 🖨️ พิมพ์บิลทุกห้อง
  4. ส่งบิลครบแล้ว กด ✅ ปิดเดือน (กดครั้งเดียวต่อเดือน)
  5. เมื่อผู้เช่าโอนเงิน ไปแท็บ 💰 จ่ายเงิน แล้วติ๊กช่องหน้าชื่อห้อง จะออกใบเสร็จให้

📅 บิลประจำเดือน

กรอกเฉพาะ "เลขมิเตอร์ล่าสุด ✏️" ระบบจำเลขเดือนก่อนให้เอง และเตือนถ้าตัวเลขผิดปกติ

กด "ปิดเดือน" หลังพิมพ์/ส่งบิลเสร็จ เดือนละ 1 ครั้ง บิลจะถูกเก็บไว้ในแท็บ "จ่ายเงิน"

📱 QR พร้อมเพย์

QR ใส่ยอดเงินของแต่ละห้องให้อัตโนมัติ (สร้าง QR ได้โดยไม่ต้องต่ออินเทอร์เน็ต)

💻 เก็บข้อมูลเป็นไฟล์ในคอม (ไม่ต้องใช้อินเทอร์เน็ต)

เลือกไฟล์ 1 ครั้ง หลังจากนั้นทุกครั้งที่แก้ข้อมูล ระบบจะบันทึกลงไฟล์นั้นให้เองทันที ข้อมูลอยู่ในคอมเครื่องนี้ ใช้ได้กับ Chrome / Edge บนคอม

ไฟล์: ยังไม่ได้เลือก
สถานะ: -

💡 คำแนะนำ

• วางไฟล์ไว้ในโฟลเดอร์ที่ซิงก์อัตโนมัติ (OneDrive / Google Drive / Dropbox) จะได้มีสำเนาสำรองบนคลาวด์ของคุณเองด้วย
• อย่าเปิดโปรแกรมนี้พร้อมกัน 2 เครื่องแล้วใช้ไฟล์เดียวกัน ฉบับที่บันทึกทีหลังจะทับ
• ถ้าเปิดแล้วเห็นแถบ "เชื่อมไฟล์อีกครั้ง" ให้กดหนึ่งครั้ง (เบราว์เซอร์ขอความยินยอมใหม่ทุกครั้งที่เปิด)

📥 ดาวน์โหลดแอปเก็บไว้ในคอม

ดาวน์โหลดเป็นไฟล์เดียว เปิดได้เลยโดยดับเบิลคลิก ไม่ต้องออนไลน์ ไม่มีหน้าล็อกอิน ข้อมูลอยู่ในคอมเท่านั้น (เวอร์ชันที่ได้จะปิดระบบออนไลน์ไว้) เปิดครั้งแรกให้ไปที่ ตั้งค่า > "เปิดไฟล์ข้อมูลที่มีอยู่" เพื่อดึงข้อมูลเดิมมาใช้

☁️ ระบบออนไลน์ (Firebase)

โปรเจกต์: - · สถานะ: -

เชื่อมแล้วข้อมูลจะซิงก์ทุกเครื่องที่ล็อกอิน (ถ้าสองเครื่องแก้ข้อมูลหมวดเดียวกันพร้อมกัน ฉบับที่บันทึกทีหลังจะทับ)

🔐 กฎความปลอดภัย Firestore (วางใน Firebase Console → Firestore → Rules) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /dormData/{doc} {
      allow read, write: if request.auth != null
        && request.auth.token.email in ['อีเมลที่1@gmail.com','อีเมลที่2@gmail.com'];
    }
  }
}

ใส่อีเมลของผู้ที่อนุญาตให้ใช้เท่านั้น แล้วกด Publish

🕘 จุดกู้คืนอัตโนมัติ

ระบบเก็บสำเนาข้อมูลให้เองก่อนทำสิ่งที่เสี่ยง (ปิดเดือน, นำเข้าไฟล์, ลบ, ยกเลิกปิดเดือน, ย้ายออก) เก็บ 6 ชุดล่าสุดในเครื่องนี้ ถ้าพลาด กด "กู้คืน" ได้เลย
